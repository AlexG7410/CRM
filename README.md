# زخم‌شفـا CRM — سامانه مدیریت ارتباط با مشتریان تخصص زخم

یک سامانه کامل مدیریت ارتباط با مشتریان (CRM) مخصوص کلینیک‌های تخصص زخم، با تم منحصر به فرد آبی-سبز و پشتیبانی کامل از زبان فارسی و RTL.

ساخته‌شده با **Django 4.2+** و **Python 3.10+**.

---

## ✨ ویژگی‌ها

این CRM شامل ۱۴ بخش کامل است:

1. 📊 **داشبورد مدیریت** — نمای کلی با نمودارها و KPIها
2. 📦 **محصولات** — کاتالوگ محصولات به تفکیک برند با تصاویر
3. 🏬 **موجودی انبار** — گزارش موجودی با نوار پیشرفت و ارزش کل
4. 🩺 **متخصصان زخم** — پروفایل پزشکان و زخم‌کارها با امتیاز و تجربه
5. 🏥 **مراکز درمانی** — شبکه همکاران درمانی در سراسر کشور
6. 🛒 **ثبت سفارش** — انتخاب محصول و مشتری با محاسبه مالیات
7. 🔍 **پیگیری مشتری** — پروفایل کامل با آمار و سفارش‌ها
8. 📋 **گزارش پرزنت روزانه** — آمار ویزیت و درآمد روزانه
9. 📨 **درخواست تدارکات** — فرم ارسال درخواست به مسئول تدارکات
10. 📥 **انبار و خروجی** — تراکنش‌های ورودی/خروجی کالا
11. 📄 **پیش فاکتور و فاکتور** — مدیریت فاکتورها با وضعیت
12. 💳 **پیگیری پرداخت‌ها** — لیست پرداخت‌ها با روش و وضعیت
13. 💬 **ارتباط آنلاین با مشتری** — چت با ارسال AJAX
14. 📜 **تاریخچه درخواست‌ها** — خط زمانی درخواست‌های مشتری
+ 💰 **ثبت فاکتور و درآمد** — نمودار درآمد + فرم صدور فاکتور

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.10 یا بالاتر
- pip
- (اختیاری) virtualenv یا venv

### مراحل نصب

```bash
# 1. ورود به پوشه پروژه
cd django-crm

# 2. ایجاد محیط مجازی (توصیه می‌شود)
python -m venv venv
source venv/bin/activate    # لینوکس/مک
# یا در ویندوز:
# venv\Scripts\activate

# 3. نصب پیش‌نیازها
pip install -r requirements.txt

# 4. کپی فایل محیط
cp .env.example .env

# 5. اعمال migrations (ساخت دیتابیس)
python manage.py migrate

# 6. بارگذاری داده‌های اولیه (برندها، محصولات، متخصصان، کلینیک‌ها، مشتریان)
python manage.py loaddata initial_data.json

# 7. بارگذاری داده‌های تراکنشی (سفارشات، فاکتورها، پرداخت‌ها، انبار، چت، گزارش‌ها)
python manage.py loaddata transactional_data.json

# 8. ایجاد حساب‌های نمایشی (مدیر + مشتری نمونه)
python manage.py init_demo_users

# 9. اجرای سرور توسعه
python manage.py runserver
```

سپس مرورگر را روی آدرس زیر باز کنید:

- **سامانه CRM (مدیریت):** http://127.0.0.1:8000/
- **پنل مشتری:** http://127.0.0.1:8000/panel/login/
- **پنل ادمین:** http://127.0.0.1:8000/admin/

### حساب‌های پیش‌فرض

| نقش | آدرس ورود | نام کاربری | گذرواژه |
|-----|-----------|-----------|---------|
| مدیر سیستم | `/login/` | `admin` | `admin123` |
| مشتری (نمونه) | `/panel/login/` | `customer1` | `customer123` |

> برای ایجاد حساب پنل برای مشتری دیگر: در پنل مدیریت → صفحه «مشتریان» → دکمه ویرایش (✏️) مشتری مورد نظر → بخش «حساب پنل مشتری» نام کاربری و گذرواژه را وارد و ذخیره کنید.

## 👤 پنل مشتری

یک پنل مستقل و کاملاً عملیاتی برای مشتریان، مجزا از پنل مدیریت. هر مشتری با حساب کاربری اختصاصی خود وارد می‌شود و فقط داده‌های خودش را می‌بیند (سفارش‌ها، پورسانت، فاکتورها و...). کاربران مشتری به پنل مدیریت و بالعکس دسترسی ندارند (با middleware جداسازی امن).

قابلیت‌های پنل مشتری:
- 📊 **داشبورد** — آمار سفارش‌ها، مجموع خرید، پورسانت و سفارش‌های اخیر
- 🛒 **سفارش‌های من** — مشاهده وضعیت و جزئیات هر سفارش
- ➕ **ثبت سفارش جدید** — انتخاب محصول با سبد خرید و محاسبه آنی مبلغ
- 💰 **پورسانت‌های من** — سابقه پورسانت به تفکیک وضعیت (در انتظار/تأیید/پرداخت)
- 📄 **فاکتورها و پرداخت‌ها** — مشاهده فاکتورها و پرداخت‌های مربوطه
- 💬 **مشاوره آنلاین** — ثبت سوال و مشاهده پاسخ متخصص
- ⭐ **ثبت رضایت‌مندی** — ثبت امتیاز و نظر درباره کیفیت
- 👤 **پروفایل من** — مشاهده و ویرایش اطلاعات تماس خود

## 🔧 تنظیمات تولید

برای استفاده در محیط تولید، فایل `.env` را به‌روزرسانی کنید:

```
SECRET_KEY=your-very-long-random-secret-key-here
DEBUG=False
```

و در `settings.py`:
- `ALLOWED_HOSTS` را به دامنه واقعی تنظیم کنید
- `DATABASES` را به PostgreSQL/MySQL تغییر دهید
- `STATIC_ROOT` را برای `collectstatic` تنظیم کنید

```bash
# جمع‌آوری فایل‌های استاتیک
python manage.py collectstatic
```
